# Withness
AI-powered immutable gift records on Solana. Describe a gift, let AI extract the details, both parties confirm to seal it on-chain.

> Record every loving gesture. Cherish it daily. Prove it when it matters.

## What is Withness?

In relationships, love is shown through actions — but actions are forgotten, misremembered, or denied. Withness fixes that.

Describe any gift or gesture in plain language. Our AI agent automatically extracts the giver, receiver, item, amount, and date. Both parties confirm with a single tap, and the record is sealed on Solana devnet as an immutable on-chain entry — permanent, tamper-proof, and always there when it matters.

## How it works

1. User describes a gift in natural language
2. AI agent extracts structured data (giver, receiver, item, amount, date)
3. Both parties confirm
4. Record is saved to Solana devnet on-chain
